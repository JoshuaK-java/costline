## CostLine project

- Work is tracked in YouTrack (project CL) via the `youtrack` MCP server.
- Before starting a card, read the article **CL-A-25 "Project context"** and the card itself (e.g. CL-39). Follow the card's Steps and "Done when".
- Windows PC, Node 26, npm. Explain anything the user must do by hand step by step.
- Branches `<type>/CL-<id>-<short-name>`; commits and PR titles start with `CL-<id>` (see CONTRIBUTING.md).
- Public repo: never commit secrets, `.env*` files, or real data (receipts, Excel exports, Gents Home files). Seed data must be made up.
- Don't change YouTrack card stages or Knowledge Base articles unless asked.
